# VBA Stock Analysis

Excel VBA macro that summarizes multi-year stock performance (ticker, yearly change, total volume) across an entire dataset in a single run.

## What it demonstrates
- VBA macro scripting for row-by-row worksheet processing
- Computing per-ticker yearly price change, % change, and total volume
- Conditional formatting driven by macro logic

## Stack
Excel, VBA

## Data
Multi-year historical stock price data for all tickers in one workbook.

## Result
The macro outputs a per-ticker summary table and flags the greatest % increase, greatest % decrease, and greatest total volume across the dataset.
